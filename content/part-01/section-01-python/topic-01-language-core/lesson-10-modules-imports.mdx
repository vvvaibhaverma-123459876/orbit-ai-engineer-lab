# Modules, packages, and import resolution

Python searches `sys.path` in order. A package directory can expose an
intentional public surface through `__init__.py`; `__main__` is the entry point
for `python -m package`. `importlib` supports explicit, dynamic loading but
should not be used to hide ordinary dependencies.

Keep imports acyclic, avoid work at import time, and test the command from a
clean environment so an accidental working-directory dependency is visible.
