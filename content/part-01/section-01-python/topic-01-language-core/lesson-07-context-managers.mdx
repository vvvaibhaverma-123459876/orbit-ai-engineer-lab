# Context managers and resource lifetime

`with` makes acquire/use/release visible. `__enter__` returns the bound value;
`__exit__` runs even when the body raises and may suppress an exception only by
returning true. `contextlib.contextmanager` turns a generator around a `yield`
into the same protocol. `ExitStack` composes a dynamic number of resources.

In AI systems this protects temporary files, database connections, locks, and
model handles. The cleanup policy belongs next to the acquisition code.
