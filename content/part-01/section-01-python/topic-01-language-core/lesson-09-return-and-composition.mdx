# Return values and composable boundaries

`return` ends a function and sends a value to its caller; falling off the end
returns `None`. A small function should make its inputs, outputs, side effects,
and failure modes visible. Compose pure transformations first, then isolate I/O
at the edge so tests do not need the network or filesystem.
