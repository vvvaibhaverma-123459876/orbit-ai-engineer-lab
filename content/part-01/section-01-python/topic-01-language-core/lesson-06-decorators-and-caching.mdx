# Decorators and caching

A decorator receives a callable and returns a callable. `functools.wraps`
preserves the wrapped function's name, docstring, and introspection metadata.
`lru_cache` memoises calls by hashable arguments; it is excellent for pure,
repeatable work and dangerous for unbounded or mutable inputs.

Before caching, measure whether recomputation dominates. Document the cache
key, lifetime, invalidation rule, and memory bound.
