# Language core synthesis and oral defence

Build the supplied constant-memory record pipeline, add tests for malformed
rows, and explain each choice aloud: where objects are shared, where iteration
is lazy, how errors are translated, and which resources are guaranteed to be
closed. The reviewer should be able to change one requirement and see where
your design absorbs it.
