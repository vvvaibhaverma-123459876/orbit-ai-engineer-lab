# Comprehensions, generators, and lazy pipelines

A list comprehension materialises all results. A generator expression or a
function containing `yield` produces one value at a time. Laziness reduces
peak memory and allows pipelines to process files larger than RAM. `yield from`
delegates iteration while preserving the generator protocol.

Choose eager data when you need repeated traversal or random access; choose
lazy data when the source is large, streaming, or only partly consumed.
