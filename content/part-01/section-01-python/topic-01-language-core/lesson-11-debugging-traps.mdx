# Debugging the five classic language traps

Diagnose rather than memorise: mutable defaults retain state, closures late-bind
loop variables, mutating a list while iterating skips elements, `is` is not an
equality operator, and shallow copies share nested objects. For each bug, write
the smallest failing example, predict the state transition, then fix it without
changing the public contract.
