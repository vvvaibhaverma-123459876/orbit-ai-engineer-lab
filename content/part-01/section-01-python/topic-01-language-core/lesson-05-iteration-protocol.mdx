# The iteration protocol

`iter(value)` asks for an iterator. `next(iterator)` asks for the next value;
the iterator signals completion by raising `StopIteration`. A `for` loop hides
this protocol, which is why custom iterables work naturally with built-ins.

Implement a finite iterator only when the state machine is clearer than a
generator. Never catch `StopIteration` inside a generator body to signal normal
completion; use `return` instead.
