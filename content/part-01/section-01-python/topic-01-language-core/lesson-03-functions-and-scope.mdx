# Functions, arguments, and scope

Arguments are evaluated at the call site; default expressions are evaluated
once when the function is defined. That is why `def add(x, bucket=[]):` shares
state across calls. Use `None` as the default and allocate inside the function.

`*args` collects positional arguments and `**kwargs` collects keyword
arguments. A closure remembers referenced variables; `nonlocal` rebinding
changes the nearest enclosing binding, while `global` changes module scope.
Prefer explicit parameters and return values over hidden mutation.

```python
def append_once(value, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(value)
    return bucket
```
