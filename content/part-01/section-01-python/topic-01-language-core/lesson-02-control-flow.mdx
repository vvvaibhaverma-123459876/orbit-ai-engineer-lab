# Control flow and pattern matching

`for` consumes an iterable; it does not require indexing. A loop `else` runs
only when the loop finishes without `break`, which makes it useful for search.
`while` repeats while a condition remains true, so every path must make progress
or terminate. Structural `match` selects by shape and can bind names; it is a
readability tool, not a replacement for every `if`.

Trace the state on paper first. For a production bug, record the invariant that
must hold at the top and bottom of each iteration.
